## Overview

Daily Dog is a once-per-day guaranteed free breed discovery that resets at midnight UTC.

## Backend

- **Endpoint**: `POST /api/dogs/daily`
- **Location**: `artifacts/api-server/src/routes/dogs.ts` (around line 1501)
- **Logic**:
  - Checks `usersTable.dailyDogAt` timestamp against start of UTC day
  - If claimed today, returns HTTP 429 with `nextReset` in response body
  - Picks a random breed (preferring uncollected if `collectedIds` sent in request body)
  - Increments `collectionCount`, `xp`, sets `dailyDogAt` to now
  - XP amount determined by `XP_PER_RARITY` table (common=10, uncommon=25, rare=60, legendary=150)

## Frontend

- **Hook**: `useClaimDailyDog` from `@workspace/api-client-react` (auto-generated by Orval)
- **ScanContext** (`artifacts/mobile/context/ScanContext.tsx`):
  - Exposes `claimDaily()` async function, `dailyDogLoading` boolean, `dailyDogError` string|null
  - On success: builds a `DetectBreedResult`-compatible object and opens the same `DetectionResultModal`
  - On 429 error: shows `Alert.alert("Daily Dog", msg)` with server's message
- **Home screen** (`artifacts/mobile/app/(tabs)/index.tsx`):
  - Amber "DAILY DOG" card with `gift` icon above the collection progress card
  - Tapping triggers `claimDaily()`, disabled while loading

## Schema

- `dailyDogAt` column added to `usersTable` (nullable `timestamp with time zone`)
- OpenAPI schema: `DailyDogRequest` and `DailyDogResult`
